# weather-app
A modern weather web app that fetches and displays real-time weather data based on user input.

-> How It Works
1.User enters a city name
2.Frontend sends request to backend (/api/weather)
3.Backend securely calls weather API
4.Data is returned and displayed on the UI


-> Tech Stack
HTML
CSS
JavaScript (Vanilla JS)
Weather API (OpenWeather)
Vercel (Deployment + Backend)

-> Setup & Run
Clone the repository
Install dependencies (if any)
Add your API key in environment variables:
OPENWEATHER_API_KEY=your_api_key_here
Deploy using Vercel
